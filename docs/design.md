# 植物大战僵尸 · 庭院保卫战

纯静态 HTML/CSS/JavaScript 游戏，可双击 index.html 或通过 Vite 打开。所有图像和声音保存在本地。游戏引擎与 DOM 绘制分离，时间步进不依赖刷新率。

5×9 草坪；向日葵、豌豆射手、坚果墙、寒冰射手、双发射手、樱桃炸弹、神水滴射手、西瓜投手；普通、路障、铁桶僵尸；阳光掉落与收集、种植费用和冷却、碰撞和啃食、寒冰减速、范围爆炸、割草机、胜负与下一关。三关递增难度，每关三波。默认进入冒险模式：点击开始后边种边打，种植消耗阳光、有冷却，按正常波次迎战。自由模式可先不限时免费布阵、无冷却、神水滴射手无数量限制；准备时不启动植物计时或僵尸波次，提示框位于草坪上方。主动点击开始才启动三波战斗，保留阵型，补种恢复费用和冷却。

桌面使用鼠标，手机使用点击；1–8 选植物、S 铲子、空格暂停、Esc 取消或关闭弹窗。含图鉴、玩法说明、音效开关、全屏、重开和本地最佳进度。浏览器失焦自动暂停。

验证引擎的资源校验、伤害、减速、爆炸、割草机和胜负；用 Playwright 测试真实种植、收集、暂停、选卡、对话框、手机布局和控制台错误。

## 独立僵王挑战

页面上方提供无需解锁的入口。直接切换后进入免费、无冷却的准备阶段，点击开始 3 秒后出现 12000 生命的机甲僵王。其固定在右侧，中间三行可攻击。定期召唤普通/路障/铁桶援兵；标记一个种植格，2 秒后造成 1800 伤害；半血后技能频率提高。技能计时受暂停控制，僵王死亡后停止召唤，清理残余援兵才获胜。挑战可直接重试；其胜负不改变冒险关卡的解锁进度。神水滴射手的伤害、数量规则不变。

## 三模式切换

游戏内部统一显示冒险、自由、僵王三个模式按钮，适用于全屏和手机。切换直接重置对局到准备阶段；保留冒险通关和所选关卡、自动拾取偏好。暂停和结算内提供同样的切换按钮。自由模式先免费布局再开打，战斗使用常规波次、费用和冷却，可以正常胜负结算。仅冒险胜利更新关卡进度。

## 手机布局与触控

手机使用独立 mobile.css，以动态视口和安全区约束游戏高度。竖屏放大草坪并原生横向滚动，缩略图呈现整场态势、视野并支持点击定位；全景按钮切回完整战场。横屏将卡槽改为左侧纵向滚动、工具放右侧。种植仍由点击触发，原生滚动取消点击，触摸不产生鼠标悬浮预览。模式切换保持可见，非核心控制收进暂停菜单，准备按钮不覆盖种植格。
