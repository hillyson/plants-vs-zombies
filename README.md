# 植物大战僵尸 · 庭院保卫战

可直接在浏览器玩的经典白天庭院同人游戏。中文界面，所有角色动画、背景和声音均保存在本地。

## 打开就玩

在线游玩：[GitHub Pages](https://hillyson.github.io/plants-vs-zombies/)。推送到 `main` 后，GitHub Actions 会自动测试、构建并更新网站。

**无需安装：双击项目里的 `index.html`。** 支持 Chrome、Edge 等现代浏览器。`dist/index.html` 也可以直接打开；移动文件时请保留同目录的脚本、样式与 `assets` 文件夹。

开发预览：

```sh
npm install
npm run dev
```

打开 http://localhost:5173 。默认进入冒险模式，点击「开始冒险」后收集阳光、边种边打，种植消耗阳光并有冷却。自由模式和僵王挑战可先免费、无冷却地布阵，点击「开始迎战」后才启动战斗；开战后补种恢复正常费用和冷却。神水滴射手不限制种植数量。声音默认关闭，可点右上角开启。

## 已实现

- 5 行 × 9 列草坪、3 个递增难度的关卡，每关 3 波僵尸。
- 向日葵、豌豆射手、坚果墙、寒冰射手、双发射手、樱桃炸弹、神水滴射手、西瓜投手。
- 神水滴射手：1000 阳光、60 秒冷却、种植数量不限，每 9.99 秒发射高伤害穿透水滴；快捷键 `7`，手机卡槽支持左右滑动。
- 普通、路障、铁桶僵尸；啃食动画、血量、冰冻减速、范围爆炸、割草机。
- 阳光默认在出现 1 秒后自动拾取，可在阳光储备下方切换手动拾取；设置在刷新、重开与下一关时保留。
- 阳光生产与收集、种植费用、独立冷却、铲除、胜负结算、下一关与重开。
- 植物图鉴、玩法指南、音乐与音效、全屏、切换标签页自动暂停。
- 鼠标与手机触控、本地保存通关进度。

快捷键：`1–8` 选植物、`S` 铲子、`空格` 暂停/继续、`Esc` 取消选择或关闭弹窗。也可以右键取消选卡。

本版本聚焦白天庭院，不包含原作完整的夜晚、泳池、屋顶和小游戏。

## 构建与验证

```sh
npm run build
npm test
npm run test:e2e
npm run test:mobile
```

浏览器测试需先运行开发服务，并安装 Google Chrome。可通过 `PLAYWRIGHT_CHANNEL` 指定其他已安装的 Playwright 浏览器通道，`GAME_URL` 指定测试网址。测试同时检查源文件和构建产物的 `file://` 直接运行，截图输出到 `test-results/`。

- `engine.js`：独立游戏状态和时间步进，不依赖 DOM。
- `app.js`：绘制、音频、操作和弹窗。
- `style.css`：响应式界面与动画。
- `tests/engine.test.cjs`：资源、冷却、伤害、减速、爆炸、割草机和胜负测试。
- `tests/browser.cjs`：实际浏览器点击、触控、游戏状态、素材和本地文件验证。

素材来源与权利信息见 [ASSETS.md](ASSETS.md)。本项目是非官方同人作品。

## 僵王挑战

游戏上方的模式切换栏直接点击「僵王挑战」，无需解锁关卡或额外确认。仍可免费布阵、种满神水滴射手，然后手动开始。

僵王拥有 12000 点生命，位于场地右侧，中间三行都能攻击它；会召唤援兵，标记草坪 2 秒后造成 1800 点砸击伤害，半血后召唤和砸击更加频繁。击败僵王后需清理剩余援兵才获胜。神水滴射手保留原本伤害。挑战结果不改变冒险模式解锁进度。

## 模式自由切换

游戏上方的切换栏可直接选择「冒险模式」「自由模式」「僵王挑战」。暂停和结算弹窗内也可切换。切换会清空当前对局，进入目标模式的准备阶段；冒险通关记录、当前选择的冒险关卡和自动拾取设置保留。点击正在进行的当前模式不会重置对局。

自由模式先布局再开打：准备阶段不限时，免费种植、无冷却，可以种满 45 格神水滴射手。点击「开始迎战」后保留阵型，启动三波常规僵尸；补种需要阳光并有冷却。击退全部僵尸即可获胜，自由模式不会解锁冒险关卡。

## 手机操作

手机端隐藏页眉、装饰和提示区，游戏适配屏幕可用高度与安全区。竖屏底部点选植物卡，再点草坪种植；左右滑动放大的草坪不会误种。缩略图显示植物、僵尸和当前视野，点击可快速定位，也可点「全景」查看整片草坪。横屏自动改为左侧上下滑动卡槽、右侧工具栏，为五条路线腾出更多高度。

「菜单」可打开选关、图鉴、玩法、声音、全屏和重开；打开菜单时暂停战斗。旋转屏幕保留当前对局。自动拾取、铲子、暂停和取消选卡按钮均适配触控。`npm run test:mobile` 使用 Chrome 手机模拟及原生触摸事件验证滑动、种植、旋转、全屏与六种手机尺寸，不代替真机兼容性测试。

## 西瓜投手

快捷键 `8`，300 阳光、7.5 秒冷却、300 生命。每 3 秒向本行最近的僵尸抛投西瓜，直接伤害 80，落点左右约一格及相邻行的其他僵尸受到 26 点溅射伤害。准备阶段规则与其他植物一致。西瓜飞行受暂停控制，目标死亡后仍落在最后追踪的位置；中间三行可以攻击僵王。手机卡槽滑动到末尾即可选用。
